Flujo guiado

La página puede llevar al usuario paso a paso desde la selección del caso hasta la base final del PAE.

Etapa clínica

Permite clasificar el caso como preoperatorio, postoperatorio, hospitalización o consulta externa.

Síntomas sugeridos

Se pueden mostrar síntomas frecuentes para ayudar a construir un caso clínico más coherente.

Secciones del PAE

La estructura puede dejar claro qué apartados se van a trabajar dentro del documento final.

Cómo se construiría el PAE

El flujo ahora parte del tipo de PAE que el usuario necesite elaborar.

Paso 1

  • Elegir entre PAE corto o PAE largo.
  • Si es corto, escoger preoperatorio o postoperatorio.

Paso 2

  • Seleccionar patología o problema de salud.
  • Agregar datos del paciente y contexto clínico.

Paso 3

  • Definir etapa clínica y síntomas compatibles.
  • Organizar entrevista, valoración y anamnesis según el tipo de PAE.

Paso 4

  • Generar la base del PAE.
  • En corto: una etapa específica.
  • En largo: pre, trans y post completos.

¿No está el caso que buscas?

Más adelante esta sección puede servir para generar una base PAE a partir del problema de salud que escriba el usuario. La IA no buscaría solo definición, sino una estructura lista con valoración, posibles diagnósticos, NOC, NIC y cuidados.

Idea futura:

El usuario escribe la condición o caso clínico → el sistema revisa si ya existe → si no existe, propone una ficha PAE inicial y luego se guarda evitando duplicados o sinónimos repetidos.
