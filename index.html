Más orden, menos ruido visual

Lo pesado ya no vive todo junto. La idea es que cada parte importante tenga su propio HTML y que esta portada solo sirva para guiar.

Módulos principales

Desde aquí el usuario entra directo a lo que necesita sin cargar una sola página con demasiadas secciones al mismo tiempo.

Crear PAE

Módulo para construir un PAE corto o largo, escoger etapas, seleccionar síntomas y generar la ruta de trabajo.

Ver ejemplos de PAE

Espacio para consultar fichas base ya armadas, como apendicitis, hipertensión, diabetes o neumonía.

IA para PAE

Parte separada para trabajar generación automática de contenido o búsqueda de información clínica sin ensuciar el inicio.

Cómo queda organizada MediGuía

Así se reparte mejor la plataforma para que crezca sin hacerse un caos visual ni técnico.

Lo que se queda en esta portada

  • Presentación general del proyecto.
  • Accesos rápidos a los módulos.
  • Explicación simple de la estructura.
  • Navegación limpia y clara.

Lo que va en archivos aparte

  • generador-pae.html para construir PAE.
  • base-pae.html para consultar ejemplos.
  • ia-pae.html para la parte de IA e info.

Siguiente paso recomendado

Con esta portada ya limpia, lo mejor ahora es tomar el archivo funcional que ya tenías y convertirlo en generador-pae.html.
