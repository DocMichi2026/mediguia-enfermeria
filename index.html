MediGuía Enfermería

MediGuía para hacer PAE

Esta página ya no está pensada como una enciclopedia de patologías, sino como una guía práctica para construir procesos de atención de enfermería. La idea es encontrar una condición clínica y ver directamente valoración, diagnósticos, resultados esperados, intervenciones y cuidados.

💗

Enfoque práctico

Buscar rápido, organizar la información y convertirla en una base útil para tareas, exposiciones y planes de cuidado de enfermería.

Cómo se construiría el PAE

En el código que compartiste se veía bien la idea de manejar un flujo por pasos. Aquí lo adapté para que encaje con MediGuía Enfermería y con el enfoque de PAE. fileciteturn0file0

Paso 1

  • Seleccionar patología o problema de salud.
  • Definir si el caso partirá de una base existente o desde cero.

Paso 2

  • Completar datos del paciente.
  • Agregar valoración inicial y contexto clínico.

Paso 3

  • Elegir etapa clínica.
  • Marcar síntomas compatibles con el caso.

Paso 4

  • Generar base del PAE.
  • Editar diagnósticos, NOC, NIC y cuidados según necesidad.

¿No está el caso que buscas?

Más adelante esta sección puede servir para generar una base PAE a partir del problema de salud que escriba el usuario. La IA no buscaría solo definición, sino una estructura lista con valoración, posibles diagnósticos, NOC, NIC y cuidados.

Idea futura:

El usuario escribe la condición o caso clínico → el sistema revisa si ya existe → si no existe, propone una ficha PAE inicial y luego se guarda evitando duplicados o sinónimos repetidos.
